# Security policy

## Supported versions

Until the first stable release, security fixes are applied only to the latest
version on the default branch.

## Reporting a vulnerability

Do not disclose a vulnerability in a public issue. Use GitHub's private
security-advisory feature for this repository. Include reproduction steps, the
affected version, and the potential impact.

Because this package controls physical machinery, also report behavior that can
cause unintended motion, bypass limits, or leave ROS resources in an unsafe
state.
